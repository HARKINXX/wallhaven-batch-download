# wallhaven-batch-download# Wallhaven 批量下载原图

<img width="282" height="377" alt="image" src="https://github.com/user-attachments/assets/a1b1b44f-0a48-4967-b262-439bb6dfd015" />

一个用于 Microsoft Edge 的油猴（Tampermonkey）脚本，在 wallhaven.cc 的列表页把当前页的高清**原图**批量下载到本地，支持数量上限、自动翻页、指定子目录、已下载去重。

- 脚本文件：`wallhaven-batch-download.js`（本目录内）
- 适用页面：`https://wallhaven.cc/*` 中所有带缩略图列表的页面（排行、热门、最新、搜索结果、标签页、自己的收藏页等）

---

## 一、功能特性

| 功能 | 说明 |
| --- | --- |
| 批量下载原图 | 解析详情页拿到 `w.wallhaven.cc` 上的**原图直链**，不是缩略图，也不靠猜后缀，png / jpg 都能下对 |
| 下载数量 | 可设上限，**跨页累计**计数，只被“下载成功”消耗 |
| 翻页次数 | 0 = 只下当前页；N = 本页下完自动往后翻 N 页 |
| 下载位置 | 指定相对默认下载目录的子目录，如 `wallpaper`、`wallpaper/4k` |
| 已下载去重 | 按壁纸 ID 记账，同一张不会重复下载，可随时查看条数并清空 |
| 可拖动浮窗 | 按住头部拖动面板，位置自动记忆 |
| 记录可收起 | 下载记录列表可一键收起/展开，状态记忆 |
| 不干扰浏览 | 面板只出现在列表页；`Alt+Q` 快速收起/展开整个面板 |
| 节流保护 | 每张间隔约 600ms 串行下载，翻页间隔 3 秒，避免触发限流 |

> 脚本**不做任何筛选**。分辨率、分类、SFW/纯度、排序等全部交给你在 wallhaven 站内搜索条件（右上角 Filters）里设好，脚本只按当前页面已有的缩略图逐张下载。

## 二、安装

1. 打开 Edge 扩展商店，安装 **Tampermonkey**（中文名「篡改猴」）。
2. 地址栏输入 `edge://extensions/`，在左侧打开 **开发人员模式（Developer mode）**——新版 Edge 需要这个开关才允许运行用户脚本。
3. 把 `wallhaven-batch-download.user.js` **直接拖入** Edge 窗口，弹出安装页后点「安装」。
   也可以在 Tampermonkey 面板里「添加新脚本」，清空编辑器后粘贴文件全部内容，`Ctrl+S` 保存。
4. 打开任意 wallhaven 列表页，右下角出现面板即安装成功。

---

## 三、使用

1. 在站内搜索框把筛选条件设好（分辨率、分类、纯度、排序……），得到目标列表页。
2. 在面板里按需填写：
   - **下载数量**：本次一共最多下多少张，`0` 或不填 = 不限。
   - **翻页次数**：`0` = 只下当前页；`2` = 本页 + 后面 2 页。
   - **下载到**：子目录名，留空 = 直接落 Edge 默认下载目录。
   - **跳过已下载过的壁纸**：默认勾选。
3. 点 **开始下载**。状态栏实时显示进度、成功/失败数、剩余额度。
4. 需要中断时点 **停止**：当前这一张下完后结束，已下好的文件与去重记录都会保留。

### 面板操作

- **拖动**：按住头部标题条拖动，松手即保存位置，下次打开自动复原。
- **折叠整个面板**：点头部右侧 `—`，或按 `Alt+Q`。
- **收起下载记录**：点「下载记录（N）」那一行，箭头反向即为已收起；收起后下载照常，展开仍能看到全部明细。

## 四、文件命名与存放位置

文件名格式：

```
wallhaven-<壁纸ID>-<宽x高>.<扩展名>
例：wallhaven-8g8q32-3840x2160.jpg
```

存放位置：

```
<Edge 默认下载目录>/<你填的子目录>/<文件名>
```

### 关于“下载位置”的重要限制

浏览器扩展**无法写入任意绝对路径**。`chrome.downloads` 的 `filename` 只接受相对默认下载目录的路径，这是浏览器的安全设计，任何用户脚本都绕不过去，因此脚本能做的是“默认下载目录下的**子目录**”。

想真正换盘符，两条路：

1. （推荐）到 `edge://settings/downloads` 把**默认下载位置**改成 `D:\壁纸` 之类，脚本里子目录留空，文件就直接落到那个目录。
2. 在子目录输入框里填 `D:\壁纸` 这类绝对路径——脚本会检测到并在记录区写一条黄色提示，然后自动退化为“默认目录 + 最后一级文件夹名”。不会静默出错，但也达不到你原本想要的效果。

子目录名会自动清理 Windows 非法字符（`<>:"|?*`）、去掉 `..`、最多 4 级，不需要你手动处理。

## 五、去重机制

**按壁纸 ID 记账**，不是靠文件名。每次下载**成功后立刻**写入一条 `ID → 时间戳` 到浏览器 `localStorage`。

- 只要在同一个浏览器里，无论你换了子目录、换了排序、换了搜索条件，同一个 ID 都不会再下一遍。
- **成功即记账**：中途关页面、断网、Edge 崩了，已下好的不会在下一轮被重下。
- 去重只在勾选「跳过已下载过的壁纸」时生效；关掉勾选则照常下载，只是记录继续更新。
- 记录上限 **10000 条**，超出丢弃最早的，不会撑爆本地存储。
- 面板底部按钮显示当前记录条数，点击会**二次确认**后清空——这是唯一出口，用于“故意重下”。

### 它不知道哪些情况

脚本无法访问磁盘核对文件是否存在，所以下列情形它分辨不出来：

- 你手动保存、或用了别的下载器 / 别的浏览器下过的图；
- 你把已下的文件删了、改名了；
- 你换了 Edge 配置文件、清了浏览器数据、换了电脑（`localStorage` 会一起丢）。

需要重下时，清空去重记录再跑即可。

## 六、工作原理（简述）

1. **采集条目**：从列表页的 `figure.thumb[data-wallpaper-id]` 取壁纸 ID、`a.preview` 取详情页地址、`span.wall-res` 取分辨率。
2. **取原图直链**：用 `GM_xmlhttpRequest` 请求详情页，解析 `<img id="wallpaper">` 的 `src`，得到 `https://w.wallhaven.cc/full/xx/wallhaven-<id>.<ext>`。属性顺序变化时有正则兜底。
3. **下载**：`GM_download` 触发浏览器下载（支持子目录）。若不可用则回退到 `fetch` + `Blob` + `<a download>`——已验证图床返回 `Access-Control-Allow-Origin: *`，这条回退路径可用（但回退时无法建子目录）。
4. **串行节流**：一张下完 + 随机 600ms 左右间隔才取下一张，不并发轰炸服务器。
5. **翻页续跑**：本页结束后找到 `a[rel="next"]`，把剩余额度与翻页次数写入 `sessionStorage`，3 秒后跳转；新页面加载完自动继续。续跑信息 10 分钟内有效。

脚本的权限：`GM_download`、`GM_xmlhttpRequest`，`@connect` 仅限 `wallhaven.cc` 与 `w.wallhaven.cc`，不向任何第三方发请求。

## 七、常见问题

**Q：Edge 提示“此站点尝试下载多个文件”？**
点允许即可；或到 `edge://settings/downloads` 关闭该二次确认。

**Q：下到一半大量失败，提示 HTTP 429 / 网络错误？**
wallhaven 对请求频率敏感。等几分钟再跑，或把单轮数量调小分批下；脚本已经是串行且带间隔，不要再改成并发。

**Q：某些图提示“取不到原图（需登录的受限内容）”？**
部分 restricted / NSFW 内容需要登录才能拿原图。脚本会把它记为失败并跳过，不影响其余图片。

**Q：翻页时提示“已经是最后一页了”？**
`a[rel="next"]` 不存在，说明 `?page=` 已到末尾；这是正常的结束。

**Q：点开始后没有任何反应？**
先确认面板出现的位置是不是已经拖到屏幕边缘被挡住了；再确认 Tampermonkey 图标上的数字徽标有 +1（表示脚本已注入本页）。若脚本刚更新过，刷新页面即可。

**Q：为什么不在详情页下？**
详情页没有列表，脚本也就不显示面板。

**Q：可以把间隔改成 0 吗？**
不建议。600ms 是稳定与速度的折中，压到极低容易被限流，反而更慢。

## 八、已知限制

- 浏览器扩展只能写“默认下载目录 + 子目录”，不支持绝对路径（见第四节）。
- 去重记录属于浏览器本地，跨设备 / 跨配置文件不同步（见第五节）。
- 面板只在带缩略图的列表页出现。
- 文件名不含标题或标签，只有 ID、分辨率，便于去重但对人不友好。
